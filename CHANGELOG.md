# Changelog

## 0.2.0 — 2026-10-08

### Fixed
- Duplicate Tabs erase button now actually closes duplicates. The newest tab in each duplicate group is kept; pinned, protected, or audio-playing tabs are never closed, and the Home screen tells you when that happens.
- The options page no longer clips its layout at small window widths — below 640px wide, the window scrolls horizontally instead of squeezing tiles and inputs into each other.

### Changed
- The active-page indicator under "Home" / "Tab Management" now slides between the two instead of popping into place.
